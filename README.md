# KhalutzVoice

Baixe o instalador ou a versão portátil para Windows na página de [versões](https://github.com/Sirpedrovic/KhalutzVoice/releases).

## Atualizações

A edição instalada, a partir da versão 0.3.5, verifica atualizações ao abrir. Quando encontra uma nova versão, baixa e reinicia antes de entrar no Khalutz. A edição portátil avisa quando há uma atualização e abre a página de download.
